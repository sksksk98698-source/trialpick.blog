# TrialPick 隐私权政策 (Privacy Policy)

<AffDisclaimer position="top" />

> **站点域名**：[trialpick.blog](https://trialpick.blog) ｜ **生效日期**：2026年10月1日 ｜ **版本**：v2026.1

## 导读：数据极简与纯静态隐私承诺

**TrialPick**（[trialpick.blog](https://trialpick.blog)）高度重视并全力保护读者的个人隐私与数据安全。本站点基于现代纯静态生成技术（VitePress SSG）架构搭建，恪守**“数据极简（Data Minimization）”**的原则：**除非读者主动通过电子邮件与我们联系，否则本站绝不会主动收集、存储或追踪读者的任何个人身份信息（PII）。**

---

## 一、我们收集与不收集的数据范围

### 1. 我们绝不收集的数据
- ❌ 我们不设用户注册系统，不收集您的真实姓名、手机号码或支付密码；
- ❌ 我们不部署任何侵犯隐私的第三方跨站追踪 Cookie；
- ❌ 我们绝不出售、出租或向任何商业机构转让任何读者访问数据。

### 2. 纯静态离线搜索（Pagefind）隐私保护
本站内置的全局全文检索系统基于开源的 **Pagefind** 静态引擎实现：
- 当您在搜索框输入关键词（如“光速云”、“试用测速”）时，**所有分词检索与结果匹配全部在您本地浏览器的 WebAssembly / JavaScript 沙箱中完成**；
- 您的任何搜索词**绝不会**被发送到任何远程搜索服务器，从根源上保障了您的搜索意图私密性。

### 3. 本地存储（LocalStorage）使用说明
为了提供舒适的阅读体验，本站仅在您的本地浏览器 LocalStorage 中存储一项设置：
- `vitepress-theme-appearance`：用于记忆您选择的“浅色模式（Light）”或“深色模式（Dark）”视觉偏好。此数据仅留存于您的设备本地，不上传云端。

## 二、第三方服务与外部链接免责

为了维持实验室的测试运转，本站包含指向第三方服务商官方网站的外部链接（包含经规范标记的赞助链接）：

- 当您点击这些外链离开 `trialpick.blog` 进入第三方服务商（如光速云、飞猫云等）官方站点后，本隐私政策即不再适用；
- 第三方站点拥有其独立的隐私条款与数据收集机制，建议您在向其提供任何注册信息前仔细审阅其官方隐私政策。

## 三、网络服务器日志（Server Access Logs）

当您通过浏览器访问托管在 Apache 服务器上的 `trialpick.blog` 时，Web 服务器可能会自动记录标准的 HTTP 访问日志信息（包含客户端 IP 地址、浏览器 User-Agent、访问时间与请求 URL）：
- 这些日志属于现代 Web 服务器保障服务可用性与防御 DDoS 攻击的行业标准配置；
- 服务器日志仅用于排查网络故障和维护服务器安全，系统会定期自动清空归档日志。
