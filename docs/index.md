## 四、试用或尝鲜时应该测什么核心指标？

很多新手在测试机场时往往只看测速峰值能跑到几百兆，实际上峰值带宽最容易在空载时被粉饰。真正的老手只关注以下 5 项底层网络指标，具体操作命令详见[极客级专业测速与质检方法论](/trial/how-to-test)：

1. **真实 TCP 握手延迟与抖动（Jitter）**：
   - 很多测速软件显示的 Ping 延迟仅仅是中转机房的本地回环，而非端到端真实响应。
   - 正确测试方法：使用命令行运行实际请求（如 `curl -o /dev/null -s -w '%{time_connect}\n' https://www.google.com`），观察连接握手时间的稳定性。抖动如果在 10ms 以内才算合格专线。
2. **晚高峰（20:00 - 23:00）丢包率**：
   - 白天顺畅不叫好机场，晚间八点到十一点全网国际出口高峰才是试金石。如果高峰期丢包率超过 8%，看视频就会出现明显的首屏卡顿与画质降级。
3. **DNS 污染防护与泄漏情况**：
   - 检查客户端在分流模式下是否会将域名明文发送给本地运营商 DNS 解析。好的服务商会在订阅配置中内置远程安全 DNS。
4. **流媒体原生 IP 解锁纯净度**：
   - 使用主流检测脚本测试 Netflix 原生剧集、Disney+ 与 YouTube Premium 是否正常识别地区。
5. **AI 平台（ChatGPT / Claude）风控等级**：
   - 如果某个节点打开 ChatGPT 提示“Access Denied”或频繁弹出 Cloudflare 复杂滑块验证码，说明该节点 IP 属于万人骑机房黑名单，不宜作为主力办公。

## 五、警惕免费试用的常见行业陷阱

在寻找“免费试用”的过程中，网络黑灰产常常利用用户贪便宜的心理设置钓鱼陷阱，更深入的黑幕拆解请查看[避开这四大免费加速器陷阱](/trial/traps)：

1. **永久免费的蜜罐节点窃取隐私**：
   - 某些论坛或群聊中流传的免费节点，其背后的出口服务器搭建了全流量抓包审计，明文抓取用户的访问记录、账号密码和 Cookie 会话。
2. **充100送100的跑路前夕吸资**：
   - 刚开业不到三个月的小机场突然推出极为夸张的永久年费会员或大额充值赠送，往往是机房欠费即将跑路前卷款的最后一波收割。
3. **试用期高速，付费后变慢的限速套路**：
   - 部分不良商家将试用用户分配在空载的独立专线，而付费后则将其转入拥挤的高负载低价公网中转节点。
4. **强制捆绑恶意软件或要求修改系统根证书**：
   - 凡是要求在电脑/手机上强制安装未知第三方安全根证书（Root CA）的所谓“免费加速器”，99% 存在中间人 HTTPS 解密窃密风险，切勿安装！
