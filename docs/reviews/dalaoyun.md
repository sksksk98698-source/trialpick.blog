## 二、学习与学术协同实测：Overleaf、Notion 与网课测试

为了验证其在学生高频场景下的可用性，我们在华东重点高校校园网（原生 CERNET 出口）和家庭宽带双环境下进行了多项实地拨测：

### 1. 线上团队协同（Notion / Google Docs / Overleaf）
- 测试在 Notion 中编辑含有大量多媒体嵌入与数据库的知识库页面，静态资源图片加载速度顺畅，无断同步现象；
- 在线编译 Overleaf LaTeX 论文工程，双向 WebSocket 实时长连接保持稳定，连续输入 1 小时未见断线重连弹窗。

### 2. 海外公开课与教学视频播放（Coursera / edX / YouTube 1080P）
- 测试 Coursera 计算机全英文公开课，视频缓冲时间在 1 秒左右，1080P 全高清画质播放全程无卡顿；
- 在 YouTube 上观看 4K 60FPS 极高清视频时，偶有缓冲等待，但切换至 1440P 或 1080P 后完全能够实现即拖即播。

### 3. 校园网高峰时段稳定性
- 每天晚上 21:00 至 23:00 为宿舍区网络用网巅峰期，受到校内出口总带宽与外网 QoS 双重挤压，丢包率会上升至 3%-5% 左右。对于网页阅读与聊天毫无影响，但大额数据文件同步建议避开此时间段。
