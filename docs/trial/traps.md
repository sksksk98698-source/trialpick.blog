## 陷阱一：全流量嗅探与钓鱼蜜罐节点（Credential Harvesting）

这是危害最大、最具隐蔽性的安全风险。黑客或黑灰产团伙会自费搭建所谓的“公益免费节点”，并通过脚本在全网大量扩散。

### 攻击原理分析：
- **中间人攻击（MITM）**：当你通过不受信任的代理节点发送数据时，出口服务器管理者拥有对所有未加密流量（如 HTTP 协议明文请求、部分弱加密传输）的完全窥探权限；
- **凭证抓取**：攻击者在服务器端部署全流量抓包程序，自动化检索并过滤诸如用户注册邮箱、明文 Cookie、密码重置 Token 以及敏感浏览历史；
- **会话劫持**：攻击者利用抓取到的 Cookie 伪装登录你的社交媒体账号、邮箱甚至个人云盘，导致灾难性的隐私外泄。

---

## 陷阱二：强制要求安装定制客户端或导入根证书（Root CA）

某些自称“一键免费连接”的加速器软件，要求用户必须下载其专属的 `.exe` 或 `.apk` 安装包，甚至在安装过程中弹出提示：**“必须安装并信任安全证书才能正常加速”**。

::: danger 绝密致命红线：严禁信任未知根证书！
- 正常合规的代理协议（如 VLESS, Trojan, Shadowsocks）**绝对不需要**在你的操作系统中安装全局系统根证书（Root CA）；
- 一旦你在 Windows 或 iOS/Android 中信任了未知的根证书，攻击者就可以对你在网上浏览的所有本应加密的 **HTTPS 流量进行合法解密**！
- 你的网银登录、密码输入、私人聊天，在攻击者屏幕前将彻底变为毫无防护的明文裸奔！
:::

## 陷阱三：“试用期特权专线，付款后分配垃圾中转”

许多不良商家深谙用户的验货心理，专门开发了欺骗性的“智能调度系统”：

1. **新用户试用阶段**：系统将你的流量调度到专门预留的、空载低延迟的高规格专线节点上，让你测速跑出上百兆、视频秒开；
2. **一旦付款完成**：系统在后台静默将你的订阅链接路由切换至廉价、超售严重的高负载公网中转节点；
3. **真实体验骤降**：原本丝滑的连接瞬间变成高峰期持续丢包，由于很多用户已经完成付款，商家便以“机房临时维护”等借口拖延应付。

## 陷阱四：“充 100 送 100”的大额充值跑路收割盘

代理网络行业平均每季度都会涌现一批寿命极短的“跑路盘”：

- **早期铺垫**：先以极低的价格（如 5 元/月）在各大社区引流，积累第一批口碑；
- **突然大促销**：在运营 2 - 3 个月、用户规模达到峰值时，突然推出所谓“周年庆充100送100”、“99元永久会员终身免流”的夸张活动；
- **卷款跑路**：在短短数天内敛财数十万元后，商家迅速注销域名、解散 Telegram 群组，服务器因欠费被机房直接拔线关停。

## 如何建立安全的网络使用常识？

1. **坚决只使用经过开源审计的标准客户端**：如 Windows 平台的 Clash Verge Rev，iOS 平台的 Shadowrocket，Android 平台的 Sing-box，严禁运行来源不明的专用安装包；
2. **坚决放弃“永久白嫖”的幻想**：选择合理收费、价格透明的正规商业服务；
3. **优先选择运营时间长（3年以上）、口碑经受住行业周期检验的老牌服务**。
